# [PRD] 마이링크 (MyLink) - 개발자 및 크리에이터를 위한 멀티링크 서비스

본 문서는 링크트리(Linktree) 클론 서비스인 **"마이링크 (MyLink)"**의 제품 요구사항 정의서(PRD)입니다. 본 서비스는 개발자와 크리에이터가 자신들의 포트폴리오, 소셜 미디어 활동, 작업물을 한눈에 보여줄 수 있는 개인 맞춤형 랜딩 페이지를 손쉽게 구축할 수 있도록 돕습니다.

---

## 1. 프로젝트 개요

### 1.1 프로젝트명
* **마이링크 (MyLink)**

### 1.2 목적 및 배경
* **링크 파편화 해결**: 개발자와 크리에이터는 GitHub, 블로그, YouTube, LinkedIn, Instagram 등 다양한 플랫폼에서 활동합니다. 이로 인해 개인을 표현하는 링크가 파편화되어 있습니다.
* **통합 개인 브랜딩 페이지 제공**: 흩어져 있는 활동 링크들을 하나의 고유한 URL(`mylink.com/{username}`)로 묶어 제공하여, 효율적인 개인 브랜딩 및 포트폴리오 노출을 가능하게 합니다.
* **직관적인 UX 제공**: 드래그 앤 드롭을 통한 간편한 순서 편집, 모바일 프레임 기반의 실시간 미리보기를 제공하여 초보자도 쉽게 프로필 페이지를 커스텀할 수 있도록 만듭니다.

### 1.3 대상 사용자 (Target Audience)
* **IT 개발자**: 자신의 GitHub 저장소, 기술 블로그, 포트폴리오 사이트, 기술 스택 등을 효과적으로 표현하고자 하는 개발자.
* **크리에이터/디자이너**: YouTube, Behance, SNS 채널 및 작업물 링크를 보기 좋게 나열하려는 창작자.
* **1인 지식 창업자 및 프리랜서**: 자신의 연락처, 서비스 소개, 포트폴리오를 원페이지로 제공하고자 하는 사용자.

## 2. 시스템 아키텍처 및 기술 스택

* **Frontend Framework**: Next.js (App Router, TypeScript)
* **Styling & UI**: Tailwind CSS, shadcn/ui (Radix UI 기반 디자인 시스템)
* **Authentication**: Firebase Authentication (구글 소셜 로그인 전용)
* **Database**: Firebase Firestore (또는 PostgreSQL)
* **Hosting**: Vercel (Next.js 최적화 배포)

## 4. 기능 상세 설명

### F-01: Firebase 구글 로그인 & 회원가입 (필수)
* **설명**: 사용자는 이메일 가입 과정 없이 구글 계정으로 즉시 가입 및 로그인을 수행합니다.
* **동작 흐름**:
  1. 로그인 화면에서 [Google 계정으로 계속하기] 버튼 클릭.
  2. Firebase Auth 구글 팝업/리다이렉트 창 활성화.
  3. 로그인 성공 후 최초 로그인인 경우 고유 아이디(`username`) 설정 페이지로 이동, 기존 회원이면 관리자 대시보드로 이동.

### F-02: 고유 프로필 URL 생성 (필수)
* **설명**: 회원가입 시 중복되지 않는 고유한 영문/숫자 조합의 `username`을 입력받고 이를 주소로 활용합니다.
* **규칙**:
  * 알파벳 소문자, 숫자, 하이픈(`-`), 언더바(`_`)만 허용 (최소 3자, 최대 20자).
  * 중복 검사를 통과해야 가입이 완료됨.
  * 생성된 주소: `https://mylink.com/{username}`

### F-03: 프로필 기본 정보 설정 (필수)
* **설명**: 마이링크 페이지 최상단에 노출될 프로필 정보를 관리합니다.
* **입력 항목**:
  * **아바타 이미지**: 드래그 앤 드롭 또는 파일 선택을 통해 업로드 (Firebase Storage 저장). Circular 크롭 지원.
  * **닉네임**: 프로필에 노출될 이름 (최대 30자).
  * **한 줄 소개(Bio)**: 프로필 하단에 표시될 간단한 소개 텍스트 (최대 100자).

### F-04: 링크 관리 - CRUD (필수)
* **설명**: 프로필 페이지에 표시할 링크 버튼을 생성하고 편집합니다.
* **입력 필드**:
  * **링크 제목**: 버튼에 노출될 이름 (예: `나의 개인 블로그 방문하기`).
  * **URL**: 실제 이동할 웹 주소 (정규식을 통해 `http://` 또는 `https://` 프로토콜 검증).
* **동작**:
  * [새 링크 추가] 클릭 시 비어있는 신규 링크 카드 생성.
  * 텍스트 입력 시 실시간으로 데이터 임시 저장 및 우측 미리보기 반영.
  * [삭제] 버튼 클릭 시 확인 팝업 후 즉시 DB 및 화면에서 제거.

### F-05: 링크 활성/비활성 토글 (필수)
* **설명**: 작성된 링크 카드의 우측에 활성화/비활성화 스위치(Switch)를 배치합니다.
* **동작**:
  * 토글이 `OFF` 상태일 때, 공개 프로필 뷰 페이지(`mylink.com/{username}`)에서 해당 링크가 렌더링되지 않음.
  * 관리 대시보드 및 실시간 미리보기에서도 즉시 노출 차단.

### F-06: 드래그 앤 드롭 링크 정렬 (필수)
* **설명**: 등록된 링크들의 노출 순서를 마우스 드래그를 통해 직관적으로 배치합니다.
* **동작**:
  * 각 링크 카드 왼쪽에 드래그 핸들(Drag Handle, `::` 아이콘) 배치.
  * 마우스 드래그 또는 모바일 터치 드래그를 통해 위아래 순서 변경 가능.
  * 드래그 종료(Drop) 시 DB에 순서 인덱스(`sortOrder`)가 자동으로 실시간 저장 및 업데이트.

### F-07: 실시간 미리보기 - Live Preview (필수)
* **설명**: 관리 대시보드 화면 우측에 가상의 모바일 디바이스 프레임을 배치하여 현재 설정 상황을 실시간 렌더링합니다.
* **구현 사항**:
  * 관리 대시보드는 2분할 레이아웃(좌측: 편집 대시보드, 우측: 모바일 기기 모양의 미리보기 화면) 구조로 구성.
  * 좌측 편집기에서 프로필 이미지, 닉네임, 링크 추가/수정/삭제/정렬 변경 시 우측 모바일 뷰에 리렌더링 없이 실시간으로 즉시 반영 (React/Next.js Context State 연동).

### F-08: 소셜 미디어 전용 아이콘 연동 (필수)
* **설명**: 이메일, GitHub, LinkedIn, Twitter, Instagram 등 주요 소셜 미디어는 큰 버튼 형태 대신, 프로필 페이지 최상단 혹은 최하단에 작고 심플한 아이콘 형태로 묶어서 정렬합니다.
* **동작**:
  * 관리 대시보드에 '소셜 링크 설정' 전용 섹션 제공.
  * 지원 플랫폼: GitHub, LinkedIn, Twitter/X, Instagram, YouTube, Facebook, Email 등.
  * URL 입력 시 해당 플랫폼에 매핑되는 Lucide 아이콘(또는 전용 로고 아이콘)이 공개 프로필 페이지에 가로 정렬로 렌더링됨.

### F-09: 링크 노출 예약 (선택)
* **설명**: 한시적으로 게시해야 하는 링크(이벤트, 프로모션, 일시적 모집 글 등)를 관리하기 위한 기능입니다.
* **동작**:
  * 각 링크 카드의 상세 설정 내에 '노출 예약 설정' 옵션 활성화 가능.
  * 시작 일시(Date & Time)와 종료 일시(Date & Time)를 설정.
  * 현재 시간이 설정된 범위 내에 있을 때만 공개 프로필 뷰 페이지에 자동으로 노출됨.

### F-10: 프로필 SEO 최적화 설정 (선택)
* **설명**: 사용자의 개별 프로필이 포털 검색에 잘 걸리거나, 링크를 카카오톡/슬랙 등에 공유할 때 노출되는 SEO 메타데이터를 관리합니다.
* **설정 항목**:
  * **Meta Title**: 브라우저 탭 및 검색 결과 제목 (기본값: `닉네임 (@username) - 마이링크`).
  * **Meta Description**: 검색 결과 요약 문구.
  * **Open Graph Image**: SNS 링크 공유 시 나타날 대표 이미지 업로드.

### F-11: 개발자/크리에이터 특화 컴포넌트 (선택)
* **설명**: IT 개발자 및 크리에이터들을 타겟으로 삼는 만큼, 이들의 아이덴티티를 명확히 보여줄 수 있는 커스텀 컴포넌트를 제공합니다.
* **컴포넌트 종류**:
  * **GitHub 잔디 임베드**: 사용자의 GitHub ID를 입력하면 프로필 페이지 내에 실시간 커밋 잔디 이미지가 삽입됨.
  * **YouTube/Vimeo 비디오 임베드**: 단순 링크 버튼이 아닌, 프로필 페이지 내에서 직접 재생이 가능한 영상 플레이어 프레임을 제공.
  * **Tech Stack 배지**: 자신이 사용하는 기술 스택(React, TypeScript, Go 등) 아이콘 및 배지를 프로필에 나열할 수 있는 섹션 제공.

### F-12: 방문자 및 클릭 통계 (선택 - 추후 구현 예정)
* **설명**: 작성한 마이링크의 성과를 분석하기 위한 대시보드 기능입니다.
* **제공 지표**:
  * **PV (Page Views)**: 내 프로필 페이지 총 방문 횟수 (기간별 필터 제공).
  * **Link Clicks**: 각 링크 버튼이 클릭된 총 횟수 및 클릭률(CTR).
  * **유입 경로**: 사용자가 어떤 링크(예: 인스타그램 바이오, 트위터 글 등)를 거쳐 들어왔는지에 대한 분석.

## 5. UI/UX 디자인 정책 (shadcn/ui 기반)

* **컴포넌트 설계**: Radix UI를 기반으로 하고 Tailwind CSS로 커스텀 스타일이 반영되는 **shadcn/ui** 컴포넌트를 활용합니다.
  * 사용 컴포넌트: `Button`, `Input`, `Switch`, `Avatar`, `Dialog` (확인 팝업용), `Card` (링크 리스트 표현용), `Separator` 등.
* **디자인 톤 앤 매너**: 
  * 개발자와 크리에이터 중심의 서비스이므로 현대적이고 깔끔한 미니멀/다크모드 스타일링을 디폴트로 삼습니다.
  * 차후 추가될 '마이링크 디자인 시스템'과 결합하기 쉽도록 테마 변수(CSS Variables) 구조를 사전에 세밀히 설계합니다.
* **반응형 디자인**: 
  * **편집/관리 대시보드**: 데스크톱 뷰에 최적화 (2분할 화면 - 왼쪽 입력창, 오른쪽 실시간 미리보기).
  * **공개 프로필 뷰 페이지**: 모바일 우선(Mobile-First) 디자인으로, 어떤 모바일 환경에서도 가독성과 터치 영역이 완벽히 최적화되도록 구성.

## 6. 품질 및 성능 요구사항 (Non-Functional Requirements)

* **초기 로딩 속도**: 공개 프로필 페이지는 사용자 유입 속도가 핵심이므로, Next.js의 SSR(Server-Side Rendering) 혹은 ISR(Incremental Static Regeneration)을 적용해 1초 이내에 첫 화면이 렌더링(FCP)되도록 구성합니다.
* **보안**: 
  * Firebase Auth를 기반으로 한 안전한 토큰 검증.
  * Firestore Security Rules를 설정하여 본인의 링크 데이터는 본인만 수정/삭제할 수 있도록 접근을 철저히 제한.
* **접근성 (Accessibility)**: shadcn/ui(Radix UI)의 기본 웹 접근성 표준을 준수하여 키보드 내비게이션 및 스크린 리더 호환성을 제공합니다.
