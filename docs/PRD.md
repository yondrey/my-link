# [PRD] 마이링크 (MyLink) - 개발자 및 크리에이터를 위한 심플 멀티링크 서비스

본 문서는 링크트리(Linktree) 클론 서비스인 **"마이링크 (MyLink)"**의 제품 요구사항 정의서(PRD)입니다. 본 서비스는 개발자와 크리에이터가 복잡한 설정 없이 직관적으로 자신들의 포트폴리오, 소셜 미디어 활동, 작업물 링크를 하나로 묶어 제공할 수 있는 개인 맞춤형 랜딩 페이지를 제공합니다.

---

## 1. 프로젝트 개요

### 1.1 프로젝트명
* **마이링크 (MyLink)**

### 1.2 목적 및 배경
* **파편화된 링크 통합**: 다양한 플랫폼(GitHub, 블로그, YouTube, SNS 등)에서 활동하는 사용자들이 고유한 식별용 주소(`mylink.com/{username}`)를 통해 단 하나의 랜딩 페이지로 소통할 수 있도록 돕습니다.
* **극도의 단순함(Minimalism)**: 이미지 업로드, 테마 커스텀, 드래그앤드롭 정렬 등 복잡한 요소를 배제하고, 인라인 편집과 구글 API 파비콘 추출을 적용해 사용 편의성을 극대화합니다.

### 1.3 대상 사용자 (Target Audience)
* **IT 개발자 및 엔지니어**: GitHub, 기술 블로그, 포트폴리오를 빠르게 공유하고자 하는 사용자.
* **크리에이터 및 프리랜서**: 자신들의 대표 채널 링크와 콘텐츠 링크를 직관적으로 나열하고자 하는 창작자.

## 2. 시스템 아키텍처 및 기술 스택

* **Frontend Framework**: Next.js (App Router, TypeScript)
* **Styling & UI**: Tailwind CSS, shadcn/ui (Radix UI 기반 UI 컴포넌트 라이브러리)
* **Authentication**: Firebase Authentication (구글 소셜 로그인 전용)
* **Database**: Firebase Firestore (서브 컬렉션 구조 활용)
* **Hosting**: Vercel

## 4. 기능 상세 설명

### F-01: Firebase 구글 로그인 & 회원가입 (필수)
* **설명**: 사용자는 Firebase Authentication을 사용해 구글 계정으로만 가입 및 로그인을 수행합니다.
* **동작 흐름**:
  1. 로그인 화면에서 구글 로그인 버튼 클릭.
  2. Firebase Auth 구글 소셜 인증 수행.
  3. 최초 로그인인 경우 구글 프로필 정보(displayName, photoURL)를 가져와 기본 계정을 생성하고, 고유 사용자 ID(`username`) 설정 페이지로 이동하여 가입 절차를 마무리한 후 관리자 페이지로 이동합니다.

### F-02: 고유 프로필 URL 생성 - username 기준 (필수)
* **설명**: 회원가입 시 사용자는 중복되지 않는 영문/숫자 기반의 고유한 사용자 ID인 `username`을 설정해야 합니다. 이 `username`이 URL의 고유 주소가 됩니다.
* **주소 구조**: `https://mylink.com/{username}` (경로 상에 `@` 기호는 미포함)
* **규칙 및 예외**:
  * 알파벳 소문자, 숫자, 하이픈(`-`), 언더바(`_`)만 허용 (최소 3자, 최대 20자).
  * 중복된 `username`이 존재할 수 없도록 가입 단계에서 실시간 중복 확인 기능을 수행하며, 생성 후 변경은 불가능(또는 관리 환경에 따라 제한적 허용)합니다.

### F-03: 프로필 정보 인라인 수정 - displayName & bio (필수)
* **설명**: 이미지 업로드 기능은 제공하지 않으며, 사용자의 구글 아바타 이미지(`photoURL`)를 그대로 노출합니다. 대신 화면에 크게 표시되는 이름(`displayName`)과 한 줄 소개(`bio`)는 대시보드 상에서 사용자가 수정할 수 있습니다.
* **수정 방식**:
  * 닉네임(`displayName`)과 한 줄 소개(`bio`) 영역을 클릭하면 인라인 텍스트 입력창으로 토글됩니다.
  * 포커스 해제(Blur) 또는 엔터키 입력 시 Firestore의 `displayName` 및 `bio` 값이 즉시 업데이트됩니다. (주의: `displayName`을 변경해도 URL 고유 주소인 `username`은 영향을 받지 않습니다.)

### F-04: 링크 관리 - 인라인 CRUD (필수)
* **설명**: 링크 카드 목록 내에서 모든 편집을 인라인으로 처리합니다.
* **인라인 편집 (Inline Editing) 동작**:
  * 대시보드의 링크 목록에서 제목 영역이나 URL 주소 영역을 클릭하면 별도의 팝업창 없이 즉시 해당 텍스트 필드가 입력 가능 모드로 전환됩니다.
  * 사용자가 입력을 마치고 엔터를 누르거나 입력창 바깥을 클릭(Blur)하면 즉시 Firestore의 서브 컬렉션에 자동 저장됩니다.
  * 드래그앤드롭 정렬 및 노출 순서 수정, 링크 토글(활성/비활성) 기능은 제공하지 않습니다.

### F-05: 구글 API 기반 링크 파비콘 자동 추출 (필수)
* **설명**: 링크 등록/수정 시 입력된 URL의 파비콘 이미지를 수동 등록 없이 자동으로 노출합니다.
* **구현 방식**:
  * 사용자가 입력한 URL의 도메인 주소를 분석하여 **구글 파비콘 API**(`https://www.google.com/s2/favicons?domain={domain}&sz=64`)를 사용해 파비콘 URL을 빌드하고 데이터베이스에 저장합니다.
  * 랜딩 페이지의 각 링크 카드 좌측에 이 파비콘을 아이콘으로 노출시킵니다.

### F-06: 공개 프로필 뷰 페이지 (필수)
* **설명**: 외부 방문자에게 공개되는 모바일 최적화 심플 뷰 페이지입니다.
* **구성 요소**:
  * 프로필 아바타 이미지 (구글 프로필 이미지 그대로 노출)
  * 사용자 이름 (`displayName`) 및 고유 아이디 (`@username` 형태로 작게 노출)
  * 한 줄 소개 (`bio`)
  * 파비콘 아이콘이 포함된 링크 목록 (생성일 역순 등 단순 리스트 방식 렌더링)
* **제한 사항**: 별도의 모바일 미리보기(Live Preview) 프레임이나 디자인 테마 설정은 제공하지 않으며, 모든 사용자는 shadcn/ui의 기본 미니멀 스타일 및 디폴트 컬러로 고정된 화면을 보게 됩니다.

## 5. 데이터베이스 모델링 및 스키마 구조

Firebase Firestore를 기반으로 설계하며, 사용자와 링크의 관계를 효율적으로 관리하기 위해 **서브 컬렉션(Subcollection)** 구조를 적용합니다.

### 5.1 `users` 컬렉션
* 문서 경로: `/users/{userId}` (여기서 `userId`는 Firebase Auth UID)
```json
{
  "username": "yondrey",
  "displayName": "욘드리 개발자",
  "photoURL": "https://lh3.googleusercontent.com/a/AGNmyx...",
  "bio": "재미있는 것들을 만드는 웹 개발자입니다.",
  "createdAt": "2026-05-26T13:00:00.000Z"
}
```

### 5.2 `links` 서브 컬렉션
* 문서 경로: `/users/{userId}/links/{linkId}`
```json
{
  "title": "내 GitHub 저장소",
  "url": "https://github.com/yondrey",
  "faviconUrl": "https://www.google.com/s2/favicons?domain=github.com&sz=64",
  "createdAt": "2026-05-26T13:05:00.000Z"
}
```

## 6. 제외 기능 및 추후 추가 기능

### 6.1 제외된 기능 목록
제품의 극도의 미니멀리즘과 빠른 출시(MVP)를 위해 아래 기능들은 기획 및 개발 대상에서 제외합니다.
* **드래그 앤 드롭 및 노출 순서 편집**: 링크의 인위적인 정렬 조작은 제외됩니다.
* **링크 활성/비활성 스위치**: 링크를 일시적으로 감추는 스위치 기능은 제공하지 않으며, 노출하지 않으려면 삭제해야 합니다.
* **디자인 테마 시스템**: 테마 변경(Light/Dark 스위치 외의 배경색 변경이나 버튼 커스텀)은 지원하지 않고 shadcn/ui 디폴트 스타일만 적용합니다.
* **프로필 이미지 파일 업로드**: 로컬 파일을 드래그앤드롭하여 아바타를 교체하는 서버 업로드 기능은 구현하지 않으며 구글 아바타를 고정 노출합니다.
* **모바일 기기 뷰 실시간 미리보기**: 관리 대시보드 우측의 가상 모바일 미리보기 프레임 기능을 생략합니다.
* **기타 선택적 추가 기능**: 예약 게시 설정, SEO 메타데이터 수동 커스텀, 개발자 위젯 임베드(GitHub 커밋 잔디 등) 기능은 제외됩니다.

### 6.2 추후 추가 예정 기능
* **링크 클릭 조회수 트래킹**: 방문자의 유입 로그를 자세히 기록하는 대시보드 기능은 제외하되, 추후 업데이트 버전으로 등록된 각 링크가 클릭된 횟수(`clickCount`)를 단순 집계하여 대시보드 내 인라인으로 표시해 주는 기능은 추가될 예정입니다.
```json
// 추후 links 서브 컬렉션에 추가될 속성 예시
"clickCount": 42
```
